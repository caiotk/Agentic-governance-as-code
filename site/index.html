Not a go-live gate. The full lifecycle.

Each stage is automated in the repository, so governance moves at the speed of a pull request.

  1. 01

    Validate

    The manifest records the use case, who validated it, the risk profile and a named owner. Undeclared risk scores at maximum.

    spec.lifecycle.validated
  2. 02

    Test

    Adversarial probes attack each agent’s real guard: boundary-probing, injection, scope escalation, expired credentials, spend and approval bypass.

    governance-gate.yml
  3. 03

    Productionise

    Deploys run only after the gate passes. At runtime the control plane admits compliant agents only, with signed short-lived credentials.

    deploy-dashboard.yml · src/server.ts
  4. 04

    Monitor

    Every decision lands in a hash-chained audit log. Denials alert; repeated denials trip the circuit breaker and quarantine the agent.

    src/guard.ts
  5. 05

    Support

    A daily drift monitor re-evaluates every agent and opens an issue for its owner when a review falls due or a control degrades.

    drift-monitor.yml · docs/runbooks
